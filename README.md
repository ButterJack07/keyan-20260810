# 任务 D：基于标注文档出题

之前已经完成了文档的内容标注（手工提取正文）。这一步是**基于各自标注的文档出问答题目**，用于后续评测。需产出：

- **简单问题 20 个**：答案能在单篇/单处内容中直接找到；
- **复杂问题 20 个**：需要综合多处信息、做归纳或跨段落推理才能回答；
- **改写问题**：把上面的问题改写成更口语化 / 更模糊 / 换种问法的版本。
- **需返回图片的问题 10 个** 这类问题光用文字回答说不清楚，答案必须配上文档里的某张图才算完整（例如问某个设备 / 结构长什么样、某个原理或流程的示意图等）。出题时选那些答案必然对应文档里某张具体图片的问题，并标出对应的是哪张图。

需标注相关片段位置以及答案。提供的样例文件中，“样例问题.xlsx”是ai生成的一些问题(我个人认为其中一些问题并不太符合要求，仅供参考)；“qa_pairs.jsonl”是我之前基于“产品手册.pdf”和“杂志.pdf”两个文档标注的几个问题可供参考

（格式参照上一个README.md，问题尽量均匀覆盖文档。）

## 出题方向（重点）

出题时请**站在"一位相关领域的专业人员在实际工作中使用文档助手"的角度**去问，而不是"为了测试系统能不能检索到某段文字"去问。也就是说：

- 想象使用者是真的想解决某个专业问题、查某个知识点，自然地提出问题——**问题本身要有实际意义、是人会真问的**；
- 尽量**不要**从文档里挑一句话再倒推出一个"答案就是这句话"的问题（这种题只是在考检索，不符合真实使用场景）；
- 问题的表述要自然，可以不完全照搬文档里的原词，就像人平时口头/打字提问那样。

简单说：**假设这是一个给专业人员日常使用的问答助手，你在替真实用户出他们会问的问题。**

# 评测集 eval/ — 标注规范与使用说明

> 范围：**文本侧全部**

## 0. 目录结构

```
eval/
├── README.md                 # 本文件：标注规范
├── qa_text.jsonl             # 文本问答对（简单+多跳+含图+英文）
├── qa_rewrite.jsonl          # 改写样本（口语化/模糊 → 期望改写）
├── qa_image_return.jsonl     # 图文返回测试（答案应带出哪张图）
└── docs_parsing/             # 版式解析测试（文本准确率≥95%）
    ├── manifest.jsonl        # 选定的 10+ 份文档清单 + 版式类型标签
    ├── samples/              # 放 10+ 份原始文档（从样例文档_副本拷入）
    └── gold_text/            # 每份文档人工核对的“标准文本”
        ├── README.md         # 标准文本的写法
        └── EXAMPLE__分栏__信号频谱形状相似度研究.md
```

## 1. 通用约定

- 所有标注文件为 **JSONL**（一行一个 JSON 对象，UTF-8，不加 BOM）。
- `id` 全局唯一，用前缀区分类别：`qa_`（文本问答）、`rw_`（改写）、`ir_`（图文返回）、`ig_`（通用图）。
- 文档统一用**文件名**引用（与 `样例文档_副本` 内文件名完全一致，含扩展名）。
- 页码 `page` 从 **1** 开始；不确定填 `0` 并在 `notes` 说明。
- 每条可加 `annotator`（标注人）、`checked_by`（复核人）、`notes`（备注）字段，便于追溯。

---

## 2. 各文件字段规范

### 2.1 `qa_text.jsonl` — 文本问答对
| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | str | `qa_001` |
| `question` | str | 用户问题（规范书面语） |
| `answer` | str | **标准答案，必须基于原文**，简洁准确，勿自行编造领域知识 |
| `gold_chunks` | list | 答案出处（召回率判定依据），每项 `{doc, page, quote}`，`quote` 为能唯一支撑答案的原文片段 |
| `type` | str | `simple` \| `multi_hop` |
| `hop_docs` | list | 多跳题列出需综合的多篇文档名；简单题填 `[]` |
| `need_image` | bool | 答案是否应返回图片 |
| `gold_images` | list | 若 `need_image`，填 gold 图片标识（文件名或“doc p.X 图N”） |
| `difficulty` | str | `easy` \| `mid` \| `hard`（分层看指标） |
| `lang` | str | `zh` \| `en` |

**红线**：`answer` 基于原文；`gold_chunks` 宁多标一段上下文不可标错页；`multi_hop` 必须真的需 ≥2 篇才能答全，否则退化成简单题。

### 2.2 `qa_rewrite.jsonl` — 改写样本
| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | str | `rw_001` |
| `raw_query` | str | **口语化/模糊/含错别字**的原始问法 |
| `canonical_query` | str | 期望改写方向（参考答案，非唯一解） |
| `gold_chunks` | list | `{doc, page}`，用于比“改写前后召回” |
| `phenomenon` | str | 改写考点：`口语化` \| `模糊` \| `错别字` \| `省略` \| `同义` |

### 2.3 `qa_image_return.jsonl` — 图文返回测试
| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | str | `ir_001` |
| `question` | str | 问题 |
| `answer` | str | 标准答案 |
| `gold_chunks` | list | `{doc, page, quote}` |
| `gold_images` | list | **必须返回的图**：`{doc, page, desc}`（desc 描述这是什么图，便于人工核对返回是否正确） |

### 2.4 `docs_parsing/manifest.jsonl` — 版式解析清单
| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | str | `dp_01` |
| `doc` | str | 文件名（须拷进 `samples/`） |
| `layout` | str | 版式难点：`分栏`\|`表格`\|`扫描`\|`公式`\|`条款`\|`双语`\|`图文彩页`\|`原生文本(对照)` |
| `gold_text` | str | 对应 `gold_text/` 下的标准文本文件名 |
| `scope` | str | 核对范围（如“前3页”“全文”），大文档只核对代表性页 |
