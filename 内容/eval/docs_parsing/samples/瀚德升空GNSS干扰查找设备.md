# 轻巧型无人机空中载荷平台

不同于传统工业级无人机或系留式无人机等大型空中监测平台，史上首例采用民用级无人机(DJI Mavic 3行业系列)打造的轻巧型无人机空载平台。

![(两架无人机，左侧为折叠状态，右侧为展开状态)](./图片1.png)

*   **体积小，重量轻** 1.机身体积约手掌大小，自重：915g，约为4部手机的重量
    2.监测测向设备重量：125g±10g，仅为0.5部手机的重量
*   **高度集成，性能优越** 已解决平台与系统电磁兼容问题
*   **针对1GHz-2GHz频率范围** GPS干扰、L波段卫星等重点关注信号

![(地图航线规划界面，显示西芯大道等地点，右侧为设置面板，包含航线高度、航线速度、完成动作等选项)](./图片2.png)

不仅体积小、重量轻，更以卓越的五阵元双通道相关干涉仪实现高性能、高性价比。特别是直接深度合作全球最成熟的大疆飞控平台，驻留、伴飞等多种飞行模式，支持空中路线规划定制，集成度更高，可靠性更好。


产品成熟稳定，操作简洁易懂，无需专业飞手，解决人手不足问题。联合固定站、移动站监测定位，覆盖范围广，使用场景多。且已解决平台与系统电磁兼容的问题，在GPS干扰及飞行控制干扰下，可正常通过4G通信控制，保证设备稳定安全运行。

![(监控软件界面，上方为地图显示犀浦立交等位置，中间为频谱柱状图显示GPS L频段等数据，下方显示频率1575.42MHz、实时电平40.65dBμV、飞行速度30.54km/h等数据)](./图片3.png)

![(左侧为无人机图片，右侧为功能列表)](./图片4.png)
*   适用于边境线，军事基地及常规城市无线电管理
*   GPS干扰搜索定位，辅助取证
*   各大运营商信号干扰排查，机动伴飞
*   L波段卫星信号监测，实时反馈，高精度监测
*   配合现有固定站、移动站，立体联动
