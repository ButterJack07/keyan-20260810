# gold_text — 版式解析“标准文本”写法

每份文档（见上级 `manifest.jsonl`）对应一个标准文本文件，用于和系统解析输出逐字比对，计算**文本提取准确率**。

## 写法约定
1. 一份文档一个 `.md`，文件名与 manifest 的 `gold_text` 字段一致。
2. **只核对 `scope` 指定的范围**（大文档不必全文，选代表性页即可，但要覆盖该版式难点）。
3. 用 `## [第N页]` 分页标记，**按人应有的正确阅读顺序**誊写正文（分栏文档尤其注意：按栏的正确顺序，而非 PDF 字符流顺序）。
4. **表格**：用 Markdown 表格誊写，保留行列结构，不拍平成一行。
5. **公式**：用 `$...$` / `$$...$$` 写 LaTeX。
6. **图片**：正文中图片位置用 `![图N：描述]()` 占位标记，不誊写图内像素，但要标出“这里有一张图”。
7. **页眉/页脚/水印**：不誊写（属应被清洗掉的噪声）。

## 准确率如何算（脚本约定）
- 以标准文本为基准，按字符/词做对齐，统计正确率（可用编辑距离或对齐后 P/R）。
- 表格、公式、阅读顺序错误都会拉低该份文档的准确率——正好定位是哪类版式的问题。

> 示例见同目录 `EXAMPLE__分栏__信号频谱形状相似度研究.md`。
